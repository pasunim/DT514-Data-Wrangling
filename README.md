### 4.1 `notebook_01.ipynb` — พื้นฐาน NumPy

โน้ตบุ๊กนี้ปูพื้นฐานเรื่อง NumPy ซึ่งเป็นไลบรารีคำนวณเชิงตัวเลขที่ pandas ใช้เป็นแกนหลักภายใน แบ่งเป็น 3 หัวข้อ:

**หัวข้อที่ 1: NumPy Basic**
- การสร้างอาร์เรย์ (`np.array()`) จาก list ของ Python
- การดูชนิดข้อมูล (`dtype`) และรูปร่าง/มิติของอาร์เรย์ (`shape`, `ndim`) โดยเฉพาะอาร์เรย์ 2 มิติ (เหมือนตาราง มีแถวและคอลัมน์)
- การเข้าถึงข้อมูลในอาร์เรย์ 2 มิติด้วยการระบุตำแหน่ง [แถว, คอลัมน์]

**หัวข้อที่ 2: Basic Data Manipulation**
- การเปลี่ยนรูปร่างอาร์เรย์ (`reshape`) เช่น แปลงอาร์เรย์ 1 มิติให้เป็น 2 มิติ
- การรวม (concatenate) และการแบ่ง (split) อาร์เรย์หลายตัวเข้าด้วยกันหรือแยกออกจากกัน
- การจัดการค่าที่ขาดหาย (`np.nan`) เบื้องต้นในระดับอาร์เรย์ ก่อนที่จะไปเจอแนวคิดเดียวกันแบบละเอียดกว่าในระดับ DataFrame ที่ notebook_02/03

**หัวข้อที่ 3: Computation and Transformation**
- การคำนวณเชิงตัวเลขพื้นฐาน เช่น ผลรวม ค่าเฉลี่ย ค่าสูงสุด-ต่ำสุด
- ฟังก์ชันทางคณิตศาสตร์ (mathematical functions) ของ NumPy เช่น `np.sqrt()`, `np.exp()`
- การคำนวณระหว่างอาร์เรย์กับตัวเลขเดี่ยว (scalar) และระหว่างอาร์เรย์ที่มีรูปร่างต่างกัน โดยอาศัยกลไกที่เรียกว่า **Broadcasting** (การขยายรูปร่างอาร์เรย์ให้เข้ากันโดยอัตโนมัติเพื่อให้คำนวณกันได้)

> **ทำไมต้องเรียน NumPy ก่อน Pandas:** เพราะ DataFrame ของ pandas นั้นภายในเก็บข้อมูลด้วยโครงสร้างของ NumPy การเข้าใจแนวคิดเรื่อง array, shape, broadcasting จะช่วยให้เข้าใจพฤติกรรมของ pandas ได้ลึกซึ้งขึ้น เช่น ทำไมการคำนวณระหว่างคอลัมน์ (Series) สองคอลัมน์ถึงคำนวณแบบ element-wise (ทีละตำแหน่งคู่กัน) โดยอัตโนมัติ

### 4.2 `notebook_02.ipynb` — พื้นฐาน Pandas

โน้ตบุ๊กนี้เป็นแกนหลักของทักษะ pandas แบ่งเป็น 5 หัวข้อใหญ่ ใช้ชุดข้อมูลตัวอย่าง เช่น `iris.csv` และข้อมูลจำลอง (mock data) ประกอบการสาธิต:

**หัวข้อที่ 1: Pandas Basic**
- การสร้าง **Series** (โครงสร้างข้อมูล 1 มิติ คล้าย column เดียว) จาก list
- การสร้าง **DataFrame** (โครงสร้างข้อมูล 2 มิติ คล้ายตาราง Excel) จาก list ของ list หรือจาก dictionary
- การอ่านไฟล์ CSV ด้วย `pd.read_csv()` และการตรวจสอบข้อมูลเบื้องต้นด้วย `.head()`, `.tail()`, `.info()`

**หัวข้อที่ 2: Data Selection & Indexing**
- การเลือกคอลัมน์ด้วย bracket notation (`df['column']`)
- การเลือกแถวด้วย `.iloc[]` (อ้างอิงตามตำแหน่ง) เทียบกับ `.loc[]` (อ้างอิงตาม label)
- การกรองข้อมูลแบบมีเงื่อนไข (Boolean filtering) เช่น `df[df['sepal_length'] > 6]`
- การตั้งค่าคอลัมน์ใดคอลัมน์หนึ่งเป็น index ของตาราง (`set_index`)

**หัวข้อที่ 3: Data Cleaning**
- การจัดการค่าที่ขาดหาย (missing values) ด้วย `.isnull()`, `.dropna()`, `.fillna()`
- การเปลี่ยนชื่อคอลัมน์ (`.rename()`) และการลบคอลัมน์ (`.drop()`)
- การแทนที่ค่า (`.replace()`)
- การตรวจจับข้อมูลซ้ำ (`.duplicated()`)
- การแปลงชนิดข้อมูล (type conversion) เช่น string เป็นตัวเลข หรือเป็นวันที่

**หัวข้อที่ 4: Transformation & Aggregation**
- การประยุกต์ใช้ฟังก์ชันกับข้อมูลด้วย `.apply()`
- การจัดกลุ่มข้อมูลด้วย `.groupby()` เพื่อสรุปผลตามหมวดหมู่ (เช่น สรุปเงินเดือนเฉลี่ยแยกตามแผนก)
- การสร้างตารางไขว้ (`.pivot_table()`)
- การจัดเรียงข้อมูล (`.sort_values()`)

**หัวข้อที่ 5: Merging and Reshaping Data**
- การต่อข้อมูลหลาย DataFrame เข้าด้วยกัน (`pd.concat()`)
- การรวมข้อมูลแบบ join ตามคีย์ร่วม (`pd.merge()`) คล้าย SQL JOIN
- การปรับรูปร่างข้อมูล (reshaping) เช่น `.melt()` เพื่อแปลงข้อมูลจากรูปแบบกว้าง (wide) เป็นรูปแบบยาว (long)

ท้ายโน้ตบุ๊กมีเซลล์ทดลองเพิ่มเติมที่โหลดข้อมูลจริงจาก `ifood.xlsx` มาดูตัวอย่าง (`.head()`, `.info()`, `.describe()`) เป็นการเชื่อมโยงไปสู่ notebook_03 ที่จะนำชุดข้อมูลนี้มาใช้วิเคราะห์อย่างเต็มรูปแบบ

### 4.3 `notebook_03.ipynb` — แบบฝึกหัด 30 ข้อ วิเคราะห์ข้อมูลลูกค้า iFood

โน้ตบุ๊กหลักของ Workshop นี้ เป็นแบบฝึกหัดจำลองสถานการณ์การทำงานจริง โดยมี **"คำถามจากเจ้านาย" (Question from your boss)** 30 ข้อ ให้แก้ไขทีละข้อโดยใช้ pandas กับชุดข้อมูลจริง `ifood.xlsx`

#### เกี่ยวกับชุดข้อมูล ifood.xlsx

ชุดข้อมูลนี้เป็นข้อมูลลูกค้าของธุรกิจ (ทำนองร้านอาหาร/ซูเปอร์มาร์เก็ต) ที่เก็บพฤติกรรมการตอบรับแคมเปญการตลาด มีทั้งหมด **2,205 แถว และ 27 คอลัมน์** คอลัมน์สำคัญ ๆ ได้แก่:

| คอลัมน์ | ความหมาย |
|---|---|
| `No` | หมายเลขลำดับ/รหัสลูกค้า |
| `Income` | รายได้ของลูกค้า |
| `Age` | อายุ |
| `Kidhome` / `Teenhome` | จำนวนลูกเล็ก / ลูกวัยรุ่นในบ้าน |
| `Recency` | จำนวนวันนับจากการซื้อครั้งล่าสุด |
| `MntWines`, `MntFruits`, `MntMeatProducts`, `MntFishProducts`, `MntSweetProducts`, `MntGoldProds` | ยอดใช้จ่ายในสินค้าแต่ละประเภท |
| `NumDealsPurchases`, `NumWebPurchases`, `NumCatalogPurchases`, `NumStorePurchases` | จำนวนครั้งที่ซื้อผ่านช่องทางต่าง ๆ |
| `NumWebVisitsMonth` | จำนวนครั้งที่เข้าเว็บไซต์ต่อเดือน |
| `AcceptedCmp1`-`AcceptedCmp5` | ตอบรับ (1) หรือไม่ตอบรับ (0) แคมเปญการตลาดครั้งที่ 1-5 |
| `Response` | ตอบรับแคมเปญล่าสุดหรือไม่ (1/0) |
| `Complain` | เคยร้องเรียนหรือไม่ |
| `Customer_Days` | จำนวนวันที่เป็นสมาชิก |
| `Marital` | สถานภาพสมรส |
| `Education` | ระดับการศึกษา (Graduation, PhD, Master, Basic, 2nCycle) |

#### สรุปแบบฝึกหัดทั้ง 30 ข้อ แบ่งเป็น 6 กลุ่ม

**กลุ่ม A: การสำรวจข้อมูลเบื้องต้น (ข้อ 1-5)**
1. โหลดไฟล์ Excel ด้วย `pd.read_excel()`
2. ดูข้อมูลแถวแรกด้วย `.head()` / `.head(10)`
3. ดูข้อมูลแถวสุดท้ายด้วย `.tail()`
4. ตรวจสอบโครงสร้างข้อมูล (`.shape`, `.dtypes`, `.info()`)
5. ดูค่าสถิติเชิงพรรณนาด้วย `.describe()`

**กลุ่ม B: การเลือกข้อมูล (ข้อ 6-10)**
6. เลือกคอลัมน์เดียว (เปรียบเทียบ Series กับ DataFrame)
7. เลือกหลายคอลัมน์พร้อมกัน
8. สร้าง DataFrame ใหม่จากคอลัมน์ที่เลือก พร้อมใช้ `.copy()`
9. เลือกแถวด้วย `.loc[]` (label-based)
10. เลือกแถวและคอลัมน์ด้วย `.iloc[]` (position-based)

**กลุ่ม C: การกรองข้อมูล (ข้อ 11-15)**
11. กรองตามอายุ (เงื่อนไขเดี่ยว)
12. กรองตามรายได้ (เงื่อนไขเดี่ยว)
13. กรองด้วยหลายเงื่อนไขแบบ AND (`&`)
14. กรองด้วยหลายเงื่อนไขแบบ OR (`|`)
15. กรองข้อมูลแคมเปญการตลาด (AND ระหว่างสองแคมเปญ)

**กลุ่ม D: Index และค่าที่ขาดหาย (ข้อ 16-20)**
16. ตั้งค่า index ใหม่ด้วย `.set_index()`
17. คืนค่า index กลับเป็นคอลัมน์ด้วย `.reset_index()`
18. ตรวจสอบค่าที่ขาดหาย (สร้างไฟล์ `ifood_missing.xlsx` มาสาธิต เพราะไฟล์ต้นฉบับไม่มีค่าขาดหาย)
19. ลบแถวที่มีค่าขาดหายทิ้ง (`.dropna()`) พร้อมเปรียบเทียบจำนวนแถวก่อน-หลัง
20. เติมค่าที่ขาดหายด้วยค่าเฉลี่ย (`.fillna(mean)`)

**กลุ่ม E: การแปลงและทำความสะอาดข้อมูล (ข้อ 21-26)**
21. เปลี่ยนชื่อคอลัมน์ (`.rename()`)
22. ลบคอลัมน์ที่ไม่จำเป็น (`.drop(columns=...)`)
23. แทนที่ค่าข้อความ (`.replace()`) ในคอลัมน์ Education
24. ตรวจจับข้อมูลซ้ำ (`.duplicated()`) — จำลองข้อมูลซ้ำเพื่อสาธิต
25. ลบข้อมูลซ้ำ (`.drop_duplicates()`)
26. แปลงชนิดข้อมูลของ `Customer_Days` เป็น `timedelta64` (ช่วงเวลา)

**กลุ่ม F: การสร้างฟีเจอร์ใหม่และวิเคราะห์เชิงกลุ่ม (ข้อ 27-30)**
27. สร้างคอลัมน์ป้ายกำกับ (label) จากค่า Response (0/1 → ข้อความ)
28. สร้างคอลัมน์ Income_Level แบ่งกลุ่มรายได้เป็น Low/Medium/High
29. วิเคราะห์ข้อมูลลูกค้าแบบกลุ่ม (`.groupby()`) ตามระดับการศึกษา
30. สร้างตารางไขว้ (`.pivot_table()`) เปรียบเทียบ Education กับ Response

## 7. ข้อควรระวังและ Tips

- **ต้องรันเซลล์ตามลำดับจากบนลงล่าง** เพราะหลายเซลล์อ้างอิงตัวแปรที่สร้างไว้ในเซลล์ก่อนหน้า (เช่น `df`, `df_missing`, `df_dup`) หากข้ามเซลล์ใดเซลล์หนึ่งไปอาจเจอ `NameError`
- **`.loc[]` vs `.iloc[]`:** `.loc[]` ใช้ label ของ index/คอลัมน์ และรวมขอบขวาของ slice (inclusive) ส่วน `.iloc[]` ใช้ตำแหน่งตัวเลขล้วน ๆ และไม่รวมขอบขวา (exclusive) เหมือนการ slice list ปกติของ Python
- **`&` และ `|` ต้องใส่วงเล็บครอบแต่ละเงื่อนไข** เช่น `df[(df["Age"] > 40) & (df["Income"] > 50000)]` มิฉะนั้นจะเกิด error เนื่องจากลำดับความสำคัญของตัวดำเนินการ (operator precedence)
- **การเลือกคอลัมน์ด้วย single bracket (`df["Income"]`) จะได้ Series** ส่วน double bracket (`df[["Income"]]`) จะได้ DataFrame แม้จะมีข้อมูลแค่คอลัมน์เดียวก็ตาม
- **ใส่ `.copy()` เมื่อสร้าง DataFrame ใหม่จากการเลือกคอลัมน์/แถว** หากตั้งใจจะแก้ไขข้อมูลใน DataFrame ใหม่โดยไม่กระทบต้นฉบับ เพื่อหลีกเลี่ยงคำเตือน `SettingWithCopyWarning`
- ไฟล์ `ifood.xlsx` ต้นฉบับ**ไม่มีค่าขาดหายและไม่มีข้อมูลซ้ำ** ดังนั้นแบบฝึกหัดที่เกี่ยวกับหัวข้อเหล่านี้ (ข้อ 18-20, 24-25) จึงต้องจำลองสถานการณ์ขึ้นมาใหม่ (สร้างไฟล์ `ifood_missing.xlsx` หรือคัดลอกแถวซ้ำในหน่วยความจำ) เพื่อให้เห็นผลลัพธ์การทำงานจริง
